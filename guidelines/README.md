# Brand guidelines

## Voice

Mission-first, clear, calm. Technology that serves churches and nonprofits — not flashy SaaS hype.

## Name

- **ChapelCloud** (one word, capital C on both)
- Domain: **chapel.cloud**

## Typography

- Display: **Fraunces** (headlines, brand wordmark treatment)
- Body: **Figtree**

## Color

See [`../colors/tokens.json`](../colors/tokens.json). Primary brand teal is `chapel` (`#1a5f6a`); deep ink is `#162033`; mist/cloud for light surfaces.

## Visual

- Prefer real ministry / place atmosphere (chapel light, sky, quiet interiors) over abstract purple gradients.
- On marketing surfaces, the ChapelCloud name should read as the hero-level brand signal.
- Add logo SVGs under `logos/` as they are finalized; favicon reference exists in `home-site`.
