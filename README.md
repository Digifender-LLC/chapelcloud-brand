# ChapelCloud — brand

Canonical brand system for ChapelCloud. Product and marketing repos should reference or copy from here — not invent one-off palettes or marks.

**Concept:** covering presence — a soft geometric crest of interlocking plates (protective mantle) with a central gold witness star (steady light). Durable and architectural; not fluffy tech clouds or literal religious icons.  
**Sources:** [business plan](../company/plans/business-plan.md), [ADR-0002](../company/decisions/0002-christian-operating-principles.md), UberBible lexical/verse study (see [`guidelines/foundation.md`](guidelines/foundation.md)).
