# ChapelCloud — brand

Brand assets and guidelines for ChapelCloud.

Use this repo as the canonical home for logos, type, color tokens, and export-ready files. Product repos should reference or copy from here — not invent one-off palettes.

## Layout

| Path | Contents |
|------|----------|
| [`logos/`](logos/) | SVG/PNG marks and wordmarks |
| [`fonts/`](fonts/) | Licensed font files + license notes |
| [`colors/`](colors/) | Token definitions (CSS / JSON) |
| [`guidelines/`](guidelines/) | How to use the brand |
| [`exports/`](exports/) | Social, favicon, press kit exports |
