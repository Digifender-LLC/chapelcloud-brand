# Exports

Ready-to-use derivatives of [`../logos/`](../logos/). PNG masters are generated by `logos/_generate_mark.py`.

## Specs

| Asset | Size | File / source |
|-------|------|----------------|
| Favicon | 32×32 | `favicon-32.png` ← `logos/favicon.svg` |
| Apple touch | 180×180 | `apple-touch-180.png` ← `logos/mark.svg` |
| Mark (field) | 512 / 1024 | `mark-512.png`, `mark-1024.png` |
| Mark alone | 512 / 1024 | `mark-alone-512.png`, `mark-alone-1024.png` |
| Lockups | 1024 wide | `lockup-1024.png`, `lockup-stacked-1024.png` |
| Mono / reversed | 512 | `mark-mono-512.png`, `mark-reversed-512.png` |
| PWA / Android | 192×192, 512×512 | regenerate from `logos/mark.svg` |
| OG / social | 1200×630 | `presence` or soft sky + `lockup.svg` + one short line |
| Avatar | 400×400 | `logos/mark.svg` on `presence` |
